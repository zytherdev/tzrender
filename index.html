THE npm PACKAGE

Useful UI.
No framework required.

tzrender is a small vanilla JavaScript library for common interface patterns. Every example below calls the package API you can install in your own project.

Copy examples assume you imported Render, created const ui = new Render(), and awaited ui.ready.

npm install @zyther/tzrender
