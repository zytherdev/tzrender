REUSABLE UI COMPONENTS

Ready to use in your project

These examples call the public tzrender API—not page-only effects.

Toast notifications

Show quick, accessible feedback.

render.toast({ variant: 'success', title: 'Saved!', message: 'Your changes are ready.' });

Accessible tooltips

Hover over or focus this button.

render.tooltip('#saveButton', { content: 'Saves your work', placement: 'top' });

Accordion

render.accordion({ items: [{ title: 'Question', content: 'Answer' }] });

Keyboard-accessible tabs

render.tabs({ items: [{ label: 'HTML', content: 'Structure' }] });

Progress indicators

Update a bar or ring as work completes.

const progress = render.progress({ label: 'Uploading', value: 0, showValue: true });
progress.set(65);

Skeleton placeholders

Loading preview content…

const placeholder = render.skeleton({ variant: 'card', container: '#profile' });
